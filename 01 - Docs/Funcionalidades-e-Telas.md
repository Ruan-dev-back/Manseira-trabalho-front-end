# Funcionalidades e Telas - EduStream

| Funcionalidade | Tela equivalente | Vale para o EduStream? |
| --- | --- | --- |
| Landing / pagina inicial | `LandingView.vue` | Sim |
| Cadastro e autenticacao | `auth/LoginView.vue`, `auth/RegisterView.vue` | Sim |
| Exploracao do conteudo por categoria | `FeedView.vue` | Sim |
| Upload/criacao do conteudo principal | `UploadView.vue` | Sim |
| Detalhe de um item do conteudo principal | `VideoDetailView.vue` | Sim |
| Edicao de um item do conteudo principal | `EditVideoView.vue` | Sim |
| Meus itens publicados | `MyVideosView.vue` | Sim |
| Perfil proprio / perfil publico | `profile/MyProfileView.vue`, `profile/PublicProfileView.vue` | Sim |
| Listas/favoritos personalizados | `playlist/MyPlaylistsView.vue`, `playlist/PlaylistDetailView.vue` | Sim |
| Busca | `SearchView.vue` | Sim |
| Notificacoes | `NotificationsView.vue` | Sim |
| Dashboard administrativo | `admin/AdminDashboardView.vue` | Sim |
| Denuncias / moderacao | `admin/AdminReportsView.vue` | Sim |
| Gerenciamento de usuarios | `admin/AdminUsersView.vue` | Sim |
| Gerenciamento do conteudo principal | `admin/AdminVideosView.vue` | Sim |
| Rota nao encontrada | `NotFoundView.vue` | Sim |
